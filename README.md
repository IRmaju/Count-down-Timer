Countdown Timer
A beautifully designed countdown timer to set time limits for tasks, study sessions, or fun events.

Features
Set a custom countdown in minutes and seconds.

Responsive design that works on mobile, tablet, and desktop.

Color-changing visual timer as the countdown progresses.

Alerts when the timer reaches zero (sound or message).
